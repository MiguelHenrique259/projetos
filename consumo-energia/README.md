# ⚡ Calculadora de Consumo Elétrico Inteligente

> Projeto desenvolvido para o programa de iniciação em tecnologia (Desenvolvimento de Sistemas I).

## 💡 Sobre o Projeto
Este programa em **Python** ajuda os usuários a estimarem o consumo de energia elétrica de eletrodomésticos por mês, facilitando o controle dos gastos em casa.

## 🛠️ Tecnologias Utilizadas
* [![Python](https://img.shields.io/badge/Python-3.14-blue?style=for-the-badge&logo=python&logoColor=white)](https://python.org)
* [![GitHub](https://img.shields.io/badge/GitHub-Repository-black?style=for-the-badge&logo=github&logoColor=white)](https://github.com)

## 📐 Fórmula Utilizada
O cálculo do consumo mensal em kWh é feito através da seguinte fórmula matemática:

$$\text{consumoMensal} = \frac{\text{potencia} \times \text{horasDia} \times 30}{1000}$$
